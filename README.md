# mk.dotfiles

My personal dotfiles: configs and small scripts that reflect my own preferences and setup.
Feel free to use, copy or adapt whatever you like.

Machine: [CachyOS](https://cachyos.org/) with [Niri](https://github.com/YaLTeR/niri) / [Umbriel](https://github.com/noctalia-dev/umbriel) and the
[Noctalia](https://github.com/noctalia-dev/noctalia-shell) shell, Foot, fish and Starship.
Each top-level directory is a [GNU Stow](https://www.gnu.org/software/stow/) package.

| Package | What it contains |
|---|---|
| `git` | `~/.gitconfig`, global ignores |
| `starship` | Starship prompt, palette generated by Noctalia |
| `mise` | Global tools (node, gh, claude, …) |
| `agents` | Coding agent skills shared via `~/.agents/skills` |
| `claude-code` | Claude Code instructions, subagents, statusline, settings template |
| `playwright` | Headless Playwright CLI defaults |
| `notizen` | Daily Claude Code triage of my Obsidian vault, GitHub overview, scratchpad toggle |
| `noctalia` | Idle timeouts (lock + screen off 5 min, suspend 15 min) and a hook that syncs the Noctalia palette to Firefox, Vesktop, Brave and OpenRGB |
| `openrgb` | OpenRGB profiles, login and sleep hooks |
| `pipewire` | MMX 300 EQ, autogain block, no suspend-on-idle |
| `ddev` | `ddev worktree <branch>`: git worktree as its own DDEV project |
| `brave` | Brave flags (HDR brightness fix) |
| `firefox` | `user.js` with a curated Betterfox subset |
| `wsl` | zsh setup for WSL2 |

Setup and per-package notes: [docs/setup.md](docs/setup.md).

~MK
